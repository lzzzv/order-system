# 好爽餐廳點餐系統（系統分析與設計期末報告）

大三上「系統分析與設計」期末報告。以速食餐廳為例，做了顧客用的點餐程式和員工用的後台管理程式，兩邊共用同一個 Access 資料庫。

## 主要功能

- 首頁：熱銷排行前五名（從已付款訂單的明細統計）與餐廳介紹
- 點餐端：依分類瀏覽餐點、加入購物車（懸浮購物車球顯示數量）、調整數量後送出訂單
- 後台端：員工登入，管理員工、菜單類別與餐點；收銀管理可查看訂單明細、修改付款狀態與付款方式
- 開發前先畫使用案例圖（Usecase.uml），定義五種角色與各自的功能

## 使用技術

- C#、Windows Forms
- Microsoft Access 資料庫：OLE DB 連線，七張資料表
- 交易（Transaction）：送出訂單時訂單、訂單明細、付款三張表一起寫入，任一步失敗就全部取消
- 熱銷排行用 JOIN 與 GROUP BY 統計
- 懸浮購物車球：自訂控制項繼承 Control，用 GDI+ 畫出
- StarUML：使用案例圖

## 程式架構

```
order-system/
├── 點餐頁面(新)/          點餐端（最終版本）
├── 點餐頁面/              點餐端（舊版本）
├── 後台統計/              後台管理程式
├── 首頁、首頁1、首頁2/    早期的首頁試作版本
├── 餐點圖片/              餐點照片
└── Usecase.uml            使用案例圖
```

1. 顧客在點餐端選餐、送出訂單
2. 訂單、訂單明細與付款資料以同一筆交易寫入 Access 資料庫
3. 員工在後台查看訂單、更新付款狀態、管理餐點

## 執行方式

用 Visual Studio 開啟 `點餐系統.sln`，需要安裝 Microsoft Access 資料庫引擎。
